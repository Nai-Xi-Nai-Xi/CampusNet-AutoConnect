# 校园网连上，VPN 自动开

[返回项目首页](README.md)

这个小工具会在你登录 Windows 后检查指定的校园 / 公共 Wi-Fi：发现它就连接，用保存的账号密码完成已适配的网页认证，再打开你选好的 VPN 或代理软件。首次设置好以后，就能少点几下。

**没发现指定 Wi-Fi，就直接结束，不连接别的网络、不改系统代理，也不启动 VPN。**

## 下载后怎么用

1. 在 GitHub 项目页面点绿色 **Code**，再点 **Download ZIP**。下载后右键 ZIP，选择“全部解压”，再进入解压后的文件夹。不要在压缩包预览里直接运行。
2. 打开解压出来的文件夹，双击 **`QuickSetup.cmd`**。
3. 按提示选择学校 Wi-Fi 和认证平台，填写校园网账号和密码，再选择电脑里已经安装好的 VPN 软件。
4. 如果你正连着校园网，程序会尝试自动识别深澜登录地址和接入点编号。识别不到编号时会先用常见值 `1`，你不用专门去查 `ac_id`。
5. 设置完成后，程序会提供一次连接测试。通过后，下次登录 Windows 就会自动运行。

如果设置时不在学校附近，也可以先完成设置。下次电脑发现你指定的 Wi-Fi 时，才会开始连接和认证。

## 你需要准备什么

- Windows 10 或 Windows 11 电脑。
- 学校公共 Wi-Fi 的名称，例如 `DLU`。
- 校园网账号和密码。
- 已经安装并登录好的 VPN 或代理软件。

目前提供深澜 `srun_bx1` 和 Dr.COM/ePortal 网页认证两种适配。不同学校的接口可能不一样，不能保证只填学号密码就能适配所有学校。程序会查询平台在线状态，确认当前设备已认证后才启动 VPN；只收到“登录请求成功”还不算完成。

验证码、短信、二维码登录、锐捷客户端、Dr.COM 客户端协议暂不支持。公共 Wi-Fi 如果采用这些方式，同样不能直接自动登录。

## 认证平台怎么选

**深澜 / SRun**：选择 `1`。已连接校园网时，向导会尝试自动检测登录地址和接入点编号（`ac_id`）。识别到就自动使用；识别不到会先用常见值 `1`，不需要自己查编号。这个编号由学校设置，并非每所学校都相同。如果连接测试未通过，再把校园网登录页的完整网址交给维护者协助判断。

**Dr.COM / ePortal**：选择 `2`。粘贴学校登录页网址，填写完整账号（包括学校要求的运营商后缀）。向导会从网址提取 `wlanacip`，并给出常见的接口端口。少数学校需要调整端口、`,0,` 账号前缀或 Base64 密码方式，请以本校配置为准。不知道参数时需要先核对学校说明，不能直接猜。

深澜提交密码前会按 SRun 协议计算认证数据。部分 Dr.COM/ePortal 学校只提供 HTTP；此时密码会按学校要求的原始或 Base64 格式放入登录请求，Base64 只是编码，不提供传输加密。不要通过不可信的无线网络提交账号密码；学校提供 HTTPS 时，在向导生成的 `config.json` 中将 `Drcom.ApiBase` 设为对应的 HTTPS 地址。

## 支持哪些 VPN

设置时可以选择：

- Clash Verge
- WireGuard
- OpenVPN
- Tailscale
- Windows 自带 VPN
- 其他提供命令行连接方式的软件（自定义）

请先在对应软件里完成安装、登录，并准备好它所需的配置。WireGuard、OpenVPN 和自定义命令使用的配置文件由你自己保管，不要发到公开仓库。

选择 WireGuard 或 OpenVPN 时，请用自己的 Windows 账号右键 `QuickSetup.cmd`，选择“以管理员身份运行”；普通启动时向导会先保存设置并提示你提权。OpenVPN 配置必须无需弹窗输入密码。工具发出 VPN 连接命令或启动进程，不代表远端隧道已经握手成功。

如果 VPN 软件自己设置了开机自动连接，它仍可能提前启动。要按本工具的顺序连接，请先关闭客户端自带的开机自动连接。本工具不会修改其他软件已有的自启动设置。

使用 WireGuard 时，本工具会将你选中的隧道服务设为手动启动，之后由本工具在校园网认证成功后启动它。

## 设置和测试

正常使用只需要双击 `QuickSetup.cmd`，不需要先手动编辑配置文件。设置向导会把程序放到：

```text
%LOCALAPPDATA%\CampusNet-AutoConnect
```

你也可以双击 `TestConnection.cmd` 再试一次。查看运行记录时，打开：

```text
%LOCALAPPDATA%\CampusNet-AutoConnect\runtime\campusnet.log
```

设置时输入的校园网密码会由 Windows 加密，保存在本机的 `credentials.secure` 中。它绑定当前 Windows 用户和这台电脑，复制给别人不能使用。VPN 的账号、密钥和连接配置不会由本工具代为保存。

自动运行任务只在登录 Windows 后执行一次；不是关机前认证、系统登录前认证，也不会全天常驻监听。如果开机时不在目标 Wi-Fi 附近，稍后到学校可双击 `TestConnection.cmd`。

## 常见问题

**双击设置后窗口就关了怎么办？**

请先右键 ZIP 选择“全部解压”，再打开解压后的文件夹，运行其中的 `QuickSetup.cmd`。在压缩包预览里双击时，Windows 可能只临时提取这一个文件，程序就找不到同包的安装脚本了。新版入口会提示缺少文件并保留窗口，按键后才关闭；如果你用的是旧包，请重新下载修正版。出现其他错误时，把窗口中的提示提供给维护者即可，不需要提供账号密码。

**没有自动找到登录地址怎么办？**  
在学校连上目标 Wi-Fi 后，浏览器打开 `http://neverssl.com`，等校园网登录页出现。把浏览器地址栏中的完整网址提供给维护者协助设置；不用另外寻找 `ac_id`。

**电脑在学校以外时会发生什么？**  
程序等一小会儿寻找你选的 Wi-Fi。没有发现时就结束，不会连接其他 Wi-Fi、启动 VPN 或改系统代理。

**Wi-Fi 连上了，但 VPN 没启动？**  
只有认证状态被对应平台接口确认成功后，程序才会启动 VPN。先检查账号、密码和学校认证参数，再双击 `TestConnection.cmd`。

**扫不到 Wi-Fi，但 Windows 网络列表里能看到？**  
先检查无线网卡是否打开。部分 Windows 11 电脑需要在“设置 → 隐私和安全性 → 位置”中允许桌面应用访问位置信息，才允许程序读取附近 Wi-Fi。

**怎么关闭开机自动运行？**  
在解压目录双击 `Uninstall-CampusNet.cmd`。这会移除自动运行任务，并保留本机配置和加密密码。确认不再需要后，可以自行删除 `%LOCALAPPDATA%\CampusNet-AutoConnect`。
